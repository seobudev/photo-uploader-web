기관 계정으로 로그인

기관 구글 계정으로 로그인하세요. 사진은 기관 공용 구글포토 앨범에 저장되며, 개인 구글포토와 섞이지 않습니다.

기관 연결

직원이라면 관리자에게 받은 주소로 다시 열어 주세요.
관리자라면 설치한 관리 서버(Apps Script 웹 앱) 주소를 넣으세요.

이 기관에 연결할까요?

관리자에게 직접 받은 주소가 맞을 때만 연결하세요. 모르는 링크라면 닫으세요.

처음 연결 설정

설치 안내서 순서대로 만든 값을 넣으세요. 저장하면 두 서버의 비밀값은 자동으로 맞춰집니다.

앨범 정하기

    PC 폴더째 올리기

    행사 폴더 하나, 또는 여러 행사 폴더가 든 상위 폴더(예: 2026)를 고르세요. 폴더 이름을 읽어 yymmdd_팀이름_프로그램명 앨범으로 맞춥니다. 이름에 연도·월·팀이 없으면 상위 폴더 이름에서 채웁니다. 같은 폴더를 다시 고르면 이미 올린 사진은 건너뛰고 이어서 올립니다.

    이름에 이 글자가 들어간 폴더는 그 안의 하위 폴더까지 목록에만 보이고 올리지 않습니다. 띄어쓰기·기호는 무시하며, 이 PC에 기억됩니다.

    폴더 확인

    내 팀

    사진 올리기 화면에서 기본으로 선택됩니다. 다른 팀 사진도 그때그때 바꿔 올릴 수 있습니다.

    팀 목록 관리 관리자

    약칭은 PC 폴더 이름을 읽을 때 씁니다(예: 기획). 쓰지 않는 팀은 지우지 말고 '사용'을 끄세요. 팀 이름에는 _ 를 쓸 수 없습니다.
